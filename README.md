✨ Features:
Speeds up battle animations by 5x — units move and attack significantly faster.

Speeds up the Rage Box — the Rage meter fills 5x faster.

⚠️ Important note: Spells are NOT accelerated (spellcasting animations remain at normal speed).

📦 Installation:
Download the mod archive.

Open the archive (e.g., using WinRAR or 7-Zip).

Move the folder from the archive into the mods folder in your game directory (King's Bounty: The Legend).

Launch the game and enjoy faster battles!
